# 🎬 映画で学ぶ英語 — コマンドー編

英語初心者が、馴染み深い名作映画のセリフを通して「生きた英語」を学べる学習Webアプリです。
各セリフに **日本語訳・直訳・語彙解説・日常会話での使い方の注意点** を付けています。

## 特徴

- **クリックで解説が開く** カード型UI
- **練習モード** — 日本語訳をぼかして表示し、自分で意味を考えてから確認できる
- **語彙＆使い方注意点** — 映画では特殊な文脈で使われる表現も、日常で安全に使える形を解説
- **取り込み学習** — 自分で用意したセリフを貼り付けると、1行ずつ学習カードに自動変換
- ビルド不要の **静的Webアプリ**（HTML / CSS / JavaScript のみ）

## 2つのモード

### 📚 サンプル教材タブ
こちらで用意した数フレーズに、訳・直訳・語彙・日常での使い方注意点を付けた教材です。

### ✍️ 取り込み学習タブ（自分の全セリフ学習用）
自分で用意した英語のセリフをボックスに貼り付けて「カードにする」を押すと、
1行ずつ次の機能付きの学習カードになります。

- 🔊 **発音再生** — ブラウザの音声合成で英語を読み上げ
- 📖 **辞書リンク** — 単語をクリックすると Weblio 辞書が開く
- ✍️ **訳・メモ欄** — 自分で日本語訳や気づきを書き込み（自動保存）
- **練習モード** — 自分のメモをぼかして暗記チェック

`話者: セリフ` の形式（例 `John: Let off some steam.`）なら話者名も自動で分離します。
書き込んだ内容は**自分のブラウザ内（localStorage）にのみ保存**され、外部には送信されません。
私的な英語学習のノートとしてお使いください。

## 使い方

ローカルで開く場合、`fetch` を使うため簡易サーバー経由で開いてください。

```bash
# Python が入っていれば
cd movie
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages などに置けばそのまま公開できます。

## セリフの追加方法

`data/dialogues.json` の `scenes` 配列に項目を追記するだけで増やせます。

```json
{
  "id": 4,
  "title": "シーン名",
  "character": "話者名",
  "line": "English line here",
  "translation": "日本語訳",
  "literal": "直訳",
  "context": "どんな場面のセリフか",
  "vocab": [
    { "word": "単語", "pos": "品詞", "meaning": "意味", "note": "補足" }
  ],
  "usage_notes": [
    "日常会話での使い方や注意点"
  ],
  "difficulty": 1
}
```

`difficulty` は 1〜3（★の数）。`vocab` と `usage_notes` は省略可能です。

## ⚠️ 著作権についての方針

映画の脚本（全セリフ）は著作物として保護されています。本アプリは**学習目的で短いセリフを引用の範囲で収録**し、訳・語彙・使い方の解説はすべて独自に作成しています。**脚本の全文転載は行っていません。**

セリフを大量に追加して公開・配布する場合は、引用の範囲（必要最小限・主従関係・出典明示）を守るか、権利処理済みのコンテンツをご利用ください。
